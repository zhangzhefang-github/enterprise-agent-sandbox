# 第一期定位：基于单套固定 P2P 规则的 Agent 业务执行评测环境

第一期面向 AI 应用开发者和架构师，提供可重复的企业级 Agent 业务执行评测环境：用同一套固定的 P2P 业务规则、相同的任务、初始数据和验收标准，比较不同模型、Agent 框架与工具设计的业务执行可靠性，并用于发现回归。差异化落在企业业务约束（三单匹配、部分收货、库存与应付一致性、权限边界、幂等性、异常处理、审计记录）上，而不是"Agent 能否调用工具改库"。

## Considered Options

- 企业上线前验收（规则可配置，贴合各企业）：需要可配置规则引擎，第一期范围过大，延后。
- 自研 Agent 的回归测试夹具：价值依附于单个 Agent，无法支撑横向比较，不采用。
- 成熟的通用标准化基准：核心价值尚未验证，暂不以此包装。

## Consequences

- 不做可配置的企业规则引擎；业务规则写死为一套，变更规则即变更评测基线，需要版本化以保证结果可比。
- 若企业约束无法区分出 Agent 的优劣，则差异化不成立，应重新评估定位。
