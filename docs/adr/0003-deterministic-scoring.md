# 正式计分只使用确定性规则，不依赖 LLM-as-judge

评测器依据每个评测任务预先定义的业务不变量、最终状态断言、允许操作与禁止操作，对最终业务状态和执行轨迹做确定性判定；意图从行为推断，不读取 Agent 的推理文本。LLM-as-judge 仅用于失败原因的辅助诊断，不参与计分和横向比较。原因：LLM 评分带随机性，且不同被测 Agent 暴露推理文本的程度不同，会破坏 ADR-0001 承诺的可重复与可比较。

## Consequences

- 不要求 Agent 遵循唯一的工具调用顺序；只有业务规则确实要求的顺序（如过账前须完成匹配）才作为验收条件。
- 任务编写成本上升：每个任务都要显式标注断言与允许、禁止操作。
- 行为上无法区分意图的情形统一按行为计分，以判断精度换取可复现性。
