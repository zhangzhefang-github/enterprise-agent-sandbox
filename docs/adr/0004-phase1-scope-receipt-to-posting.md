# 第一期评测范围：从收货到发票过账，采购订单为固定初始数据

被测 Agent 负责的业务阶段为：依据送货单登记收货（引起库存变化），录入供应商发票，执行三单匹配，处理异常，并在满足规则时过账形成应付记录。采购订单不由 Agent 创建，而作为评测任务的固定初始数据，因为选择供应商、定价属于开放式判断，难以用确定性断言评分（见 ADR-0003）；只做发票处理又会让库存变化绕开 Agent，测不全库存与应付一致性。

## Consequences

- 此处确定的是任务覆盖的业务阶段，不代表同一 Agent 身份同时拥有收货与过账权限；职责分离与授权另行决定。
- 付款、退货、预付款、贷项通知单不在第一期范围内。
